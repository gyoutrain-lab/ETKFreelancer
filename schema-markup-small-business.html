Schema Markup for Small Business Websites

Schema markup helps search engines understand what your website represents. For small business websites, portfolios, and GitHub Pages projects, structured data can improve trust signals and increase eligibility for enhanced search results.

What Is Schema Markup?

Schema markup is structured data written in JSON-LD format and placed inside a <script type="application/ld+json"> block. It does not change the visual design of the page.

Why It Matters for SEO

  • Clarifies page meaning
  • Strengthens trust signals
  • Supports rich results
  • Helps search engines connect related pages

Recommended Types

Use these first:
  • WebSite
  • WebPage
  • Article
  • Organization
  • Person

Simple Organization Example

{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "ETKFreelancer Studio",
  "url": "https://gyoutrain-lab.github.io/ETKFreelancer/"
}

Article Schema Example

{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Page Speed & Core Web Vitals for GitHub Pages"
}

Common Mistakes

  • Adding schema that does not match visible content
  • Using fake ratings or reviews
  • Duplicating conflicting schema blocks
  • Forgetting the canonical URL

How ETKFreelancer Uses Schema

The project uses WebPage schema on the homepage and Article schema on supporting guides. This creates a clean topical relationship between the homepage and the technical articles.

Validate Your Structured Data

Use Google's Rich Results Test:

https://search.google.com/test/rich-results

Conclusion

Schema markup is not a ranking shortcut, but it is one of the clearest ways to help search engines understand your business, your content, and the relationship between pages. Combined with good internal linking, analytics, and crawlability, it becomes part of a strong long-term SEO foundation.
